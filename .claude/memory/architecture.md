
- Sync leaves the code-push path: a commit-time transport — git hook or GitHub Action
  (`engram-sync-hooks`) — ships the on-disk memory delta straight to the hub, so memory
  stops riding repo pushes (per user, 2026-08-11; revises CONCEPTS' session-end
  personal-branch spoke).
- The hub stays a git remote, not a bespoke server — dumb transport + storage; all merge
  intelligence lives in the librarian (`engram/CONCEPTS.md`, 2026-08-10).
- The librarian is scheduled multi-source /mem-sync with branch discipline (deltas whose
  `verified` SHA isn't on trunk wait in a pending overlay) — reuses the repair engine.
- The installer wires linter, CI, and sync hooks so a fresh install is complete —
  dissolves the manual copy-in wart ([[engram-lint-ci]]).
